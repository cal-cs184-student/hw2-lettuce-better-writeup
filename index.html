Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

De Casteljau's algorithm is a process used to find a point on a Bezier curve at a parameter t between 0 and 1. It only uses linear interpolation. Each step takes the current list of points and, for every pair of neighboring points, finds the point that is a fraction t of the way from the first point to the second. This gives a new list with one fewer point. Repeating this step shrinks the list until only one point is left, and that point lies on the Bezier curve at t. Sweeping t from 0 to 1 traces out the whole curve.

For implementation, we wrote one step of the algorithm in BezierCurve::evaluateStep. It loops over each adjacent pair of input points, linearly interpolates between them using the curve's member variable t, and adds the result to a new std::vector with push_back. The returned vector has one fewer point than the input, so each call performs exactly one level of subdivision. The renderer chains these calls by feeding each output back in as the next input. Pressing E increases how many levels it computes and draws, and the green curve is drawn by running every step down to a single point at many values of t.

To demonstrate, we made our own Bezier curve with 6 control points, bzc/curve3.bzc. In our images, the 6 white control points reduce to 5, 4, 3, and 2 blue intermediate points, then to the single red point on the curve. In the last image, we moved the last control point and changed t, and the red point still lies on the new curve.

Part 2: Bezier surfaces with separable 1D de Casteljau

De Casteljau's algorithm extends to Bezier surfaces by applying the 1D version in two directions, using two parameters u and v between 0 and 1. A Bezier surface is defined by a grid of control points, which is 4x4 for the teapot. Each row of the grid is treated as its own Bezier curve, so running 1D de Casteljau on a row at u gives one point per row. Those row points then form a new Bezier curve that runs roughly along a column, and running 1D de Casteljau on them at v gives a single point that lies on the Bezier surface at (u, v).

For implementation, we wrote three functions. BezierPatch::evaluateStep performs one level of subdivision, the same as Part 1, except it works on 3D points and takes t as an argument. BezierPatch::evaluate1D calls evaluateStep repeatedly until only one point is left and returns that point. BezierPatch::evaluate calls evaluate1D on each row of controlPoints with u, collects the results, and calls evaluate1D once more on them with v. To draw the surface, the renderer evaluates each patch on a 16x16 grid of (u, v) values and splits each grid square into two triangles.
